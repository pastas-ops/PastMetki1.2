В папке www/index.html лежит само приложение PastMetki (один HTML-файл).
Его можно:
 1) загрузить в онлайн-конвертер HTML -> APK, или
 2) собрать через GitHub (вкладка Actions, файл .github/workflows/build.yml), или
 3) открыть проект в Android Studio (npm install, npx cap add android, npx cap open android).

Обновление поверх старой версии:
 - debug.keystore в корне проекта - фиксированный ключ подписи. Все APK, собранные через
   GitHub Actions с этим файлом, подписаны одним ключом и устанавливаются поверх друг друга.
 - versionCode растёт с каждой сборкой автоматически.
 - Если на телефоне уже стоит PastMetki, собранная раньше с ДРУГИМ ключом, один раз удалите её,
   потом ставьте новую.

Версия 1.0.3. Иконка приложения лежит в папке assets (icon-only/foreground/background.png),
при сборке через GitHub она ставится автоматически. firestore.rules нужно вставить в консоль Firebase
(Firestore -> Rules -> Publish).

Версия 1.0.4 - виджеты (долгое нажатие на рабочем столе -> Виджеты -> PastMetka):
 - список чатов (нажатие открывает чат),
 - список заметок (отметка переносит заметку вниз; в базе отметка применится при следующем открытии приложения),
 - напоминание о дедлайнах на 3 дня.
Нативный код виджетов лежит в папке native. Сборка через GitHub собирает его автоматически;
если нативная часть не соберётся, будет собран запасной APK без виджетов (в логе будет предупреждение).
Для сборки в Android Studio: npm install, bash native/prep.sh, python3 native/install.py, затем собрать проект.

Версия 1.1.0 - Colorful UI:
 - обновлённый тёмный интерфейс с цветными категориями и карточками;
 - экран приветствия перед входом/регистрацией;
 - домашняя панель с прогрессом чек-листов и предстоящими дедлайнами;
 - поиск по названиям заметок, пунктам задач и категориям, история поиска;
 - категории заметок: работа, учёба, личное, покупки, другое;
 - Android-виджет быстрых действий (заметка, задача, календарь);
 - GitHub Actions теперь завершает сборку ошибкой, если нативные виджеты не установлены,
   вместо публикации запасного APK без виджетов.
